Execution Architecture

Deterministic State Machine.
From Intent to Settlement.

Relay executes a 17-node LangGraph pipeline across distributed A2A merchant services — orchestrating semantic catalog retrieval, structured multi-agent negotiation, and cryptographically verified payment reconciliation.

01

Intent & Requirement Parsing

Translates unstructured user requirements, budget boundaries, and bulk quantities into typed schema specifications and shopping goal states.

02

A2A Merchant Orchestration

Queries independent merchant agents over the A2A JSON-RPC protocol, evaluates live stock availability, and negotiates volume pricing in real time.

03

Audited Settlement Gate

Renders an itemized cost breakdown with verifiable unit economics, triggering merchant-side Razorpay order creation only upon explicit user confirmation.

Core Capabilities

Engineered for Precision.
Built for Autonomy.

A production-grade multi-agent architecture executing deterministic state transitions across independent buyer and merchant services with full auditability.

01

Semantic Intent Decomposition

Extracts product specifications, volume constraints, and brand preferences into strictly typed Pydantic data models.

02

Distributed Merchant Discovery

Resolves A2A agent cards and queries live inventory matrices simultaneously across multiple vendor nodes.

03

Transparent Cost Normalization

Audits base prices, applicable discounts, and fulfillment fees into verifiable line-item unit economics.

04

Upsell & Add-On Isolation

Evaluates merchant cross-sell suggestions against user budget constraints without compromising primary goals.

05

Multi-Objective Offer Ranking

Ranks quotes using composite scoring across price efficiency, verified stock levels, and merchant reliability.

Human-in-the-Loop Safety Gate

Enforces state machine gating where financial transactions cannot proceed without explicit user authorization.

Executes merchant-created Razorpay payment sessions with cryptographic HMAC signature verification.

Persists multi-turn session snapshots, entity preferences, and episodic shopping records in durable SQLite storage.
