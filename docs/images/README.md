This directory holds screenshots and image assets used by the documentation.

To include the demo screenshots referenced by `README.md` and `docs/demo.md`, add the two PNG files with these exact names:

- `demo_screenshot_1.png` — Cart and request view
- `demo_screenshot_2.png` — Completed order and payment link

Place the files in this folder and commit them to the repository. Once added, the images will render on GitHub and in the docs pages.
